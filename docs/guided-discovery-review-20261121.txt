DESIGN AND BEHAVIOR
Normal home has the existing search and one Choose a service control. No
arbitrary category, category carousel or automatic geolocation request.
Only the current stage expands: categories, specific services, or results.
All 14 original categories remain; photographed rows are vertical, with one
column on mobile and two on desktop when readable. The service stage has
Back, Close, the selected category and All services in this category.
Results have editable category/service summaries and at most two matching
service/price rows per business; complete menus remain in existing details.

Search markup is byte-for-byte identical to the approved main form (hash
8ba0c17fc09aede40e70af62f168f90ec900f5f3e08870d4ac0ef22090f6c89a).
Suggestions, typing, submission, filters and location controls were not
redesigned. The guide updates their existing authoritative filter state.
It retains typed query constraints, explicit area and radius, clears an
incompatible child, and does not silently broaden a guided search.
Real server facets determine which specific service choices are available.
No exact matches produces change-service/change-area options, not unrelated
businesses. Partner status does not bypass matching or geographic scope.

Labels are centered over the WHOLE control, not remaining flex space:
equal left/right grid tracks + centered middle track + symmetric padding.
The left contains the existing photo (or an empty balancing track); the
right contains a 16px vector cue. At enlarged text the equal side tracks can
shrink symmetrically to admit complete words; arrows retain a 16px minimum.
Measured center error was 0px normally and <=0.004px at 320px/150% text
(subpixel rounding); arrows did not overlap labels.

Warm cream surfaces, fine orange borders, restrained shadows and 180ms
feedback reuse the current brand. Selected background, heavier text and
localized Selected wording are recognizable without color alone. No emojis,
checkmarks, underline-only selection or new decorative images were added.
Focus rings, native buttons, disclosure semantics and reduced-motion CSS
are present. Only the current heading receives transition focus; closing
returns to the launcher. Next's supported URL subscription fixes native
Back/Forward restoration without duplicate requests or a second filter store.
