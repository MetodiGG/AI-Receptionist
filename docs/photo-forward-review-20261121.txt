NARROW / ENLARGED-TEXT SAFETY DECISION
The requested full words at15–16px cannot always fit inside two tiles at320px:
actual initial measurements found Автоелектроника135px and Тенекеджийство130px
against a122px caption. Shortening, clipping and shrinking violate the hard
full-label requirements. An asynchronous preference question was sent.
For this review the implementation preserves complete names: only service grids
containing an actual localized word of14+ letters switch to one column in very
narrow containers (<=20rem). The default category grid and ordinary320px nails
grid remain two columns; all normal390px grids remain two columns.
The flag is presentation only, derived after the unchanged positive-count filter.
It does not alter labels, mappings, IDs, results, analytics or query handling.
At200% root text, grids reflow to fewer columns while retaining their fixed ratio;
All keeps equal40px side tracks and reduces only balancing gaps/padding.
320px English longest labels and1440px Bulgarian enlarged text showed no clipped
labels/captions or horizontal overflow. No displayed names were abbreviated.
This is an explicit accessibility exception to a rigid two-column narrow grid,
pending the user's preference, not an undisclosed change in filtering.
